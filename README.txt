Open locally:
1. Extract this ZIP file.
2. Keep index.html and Mohammed-Ali-Abobakr-CV.pdf in the same folder.
3. Double-click index.html to open the site in your browser.

Publish with GitHub Pages:
1. Create or open a GitHub repository.
2. Upload index.html and Mohammed-Ali-Abobakr-CV.pdf to the repository root.
3. Open Settings > Pages and choose deployment from the main branch and root folder.
4. Save and wait for GitHub Pages to publish the website.

Notes:
- This is a static HTML website; no npm, Vite, or build step is required.
- The CV buttons work when the PDF remains beside index.html with the exact filename above.
- Google Fonts require an internet connection; the page content and CV are local.
- Project cards currently link to the GitHub profile unless a specific verified project URL is configured. Replace those links with each project's repository URL when available.
- Check contact/social links and personal details before publishing publicly.
